# OpenVPN Seller Bot

Telegram-бот для продажи VPN. Работает как **VPNCreator**: вы добавляете свой скрипт и шаги
(что печатать в терминале), а бот сам ставит его на серверы и создаёт ключи. Сверху добавлено то,
что нужно для продажи: ссылки для клиентов, сроки, **рассылка новых ключей при смене IP**,
перенос клиентов на другой сервер.

---

## 🚀 Установка: одна команда

Любой VPS (Ubuntu / Debian), вход под root:

```bash
bash <(curl -sL https://raw.githubusercontent.com/k9032431-cmd/OpenVPN-Seller-Bot/HEAD/install.sh)
```

Скрипт задаст только 2 вопроса:
1. **Токен бота** от [@BotFather](https://t.me/BotFather).
2. **Напишите своему боту «Start»**, и скрипт сделает вас админом.

## 🖼 Как устроен интерфейс

- **Одно меню-панель.** Бот не шлёт новое сообщение на каждое нажатие: экран меняется на месте.
- **Чистый чат.** Ваши ответы в мастерах (имя ключа, IP, пароль) бот сразу удаляет.
- **Внизу одна кнопка «🏠 Главное меню»**, в каждом экране есть «⬅️ Назад · 🏠 Меню».
- **Главное меню показывает сводку:** у админа серверы, ключи, диллеры и «быстрый старт», у диллера его ключи,
  у клиента его ключи со сроками.
- Отдельными сообщениями приходят только файлы ключей, уведомления и ход долгой установки.

## 🤖 Работа в боте: 3 шага

### 1. 📜 Скрипт (один раз)

`📜 Скрипты` → **⚡ Готовый: OpenVPN**. Ваш скрипт и все шаги уже заполнены (таблица ниже).

Или `➕ Добавить скрипт`. Бот проведёт по шагам, как в VPNCreator:

| Шаг мастера | Что это |
|---|---|
| Название | как называется VPN (`OpenVPN`, `WireGuard`, `VLESS`…) |
| Файл | файл скрипта документом или ссылка (GitHub) |
| **Установка** | что печатать в терминале при установке: команды и ответы, каждое с новой строки |
| Проверка | команда «уже установлено?», например `test -f /etc/openvpn/server.conf` |
| **Создание ключа** | что печатать, чтобы создать ключ; `{name}` — название ключа |
| Результат | файл на сервере (`/root/{name}.ovpn`) или вывод команд (`vless://\S+`) |

Потом в карточке скрипта можно задать **🗑 Удаление ключа** и **🌐 Смена IP**.

Как бот вводит шаги: он открывает на сервере **настоящий терминал** и печатает строки по одной,
когда скрипт ждёт ответа.
- `enter` — просто нажать Enter (оставить значение по умолчанию);
- `? текст вопроса => ответ` — ответ на вопрос, который появляется **не всегда** (например,
  `? Public IPv4 address => {server_ip}` только на серверах за NAT), остальные ответы не сдвигаются;
- если скрипт не принял ответ или ждёт ввода, а шаги закончились, бот остановится и покажет, где.

Подстановки: `{name}` — название ключа, `{server_ip}` — IP сервера, `{file}` — путь к файлу скрипта.
Для «Смены IP»: `{old_ip}`, `{new_ip}`, `{old_ip_re}`.

### 2. 🖥 Сервер (один раз на сервер)

`🖥 Серверы` → `➕ Добавить сервер` → название → IP → пароль root.
Пароль бот не хранит и удаляет из чата: один раз добавляет свой SSH-ключ и дальше заходит по нему.
Скрипт ставится сам при первом ключе или сразу кнопкой **⚙️ Установить** (бот показывает каждый шаг).

### 3. ➕ Ключ

`➕ Новый ключ` → (сервер, VPN) → имя → срок. Бот даст **ссылку**. Перешлите её клиенту:
он нажмёт «Запустить» и получит ключ. Ссылка срабатывает **один раз**.

### 🌐 Сменился IP сервера

`🖥 Серверы` → сервер → **✏️ Сменить IP** → новый IP. Бот:
1. подключится по новому IP (пароль не нужен);
2. выполнит шаги «Смена IP» скрипта на сервере;
3. заменит IP во всех ключах этого сервера;
4. **сам разошлёт новые ключи всем клиентам**.

### 🚫 Сервер заблокировали

Добавьте новый сервер → откройте старый → **🔁 Перенести клиентов**.
Каждый клиент получит новый ключ от нового сервера, сроки сохранятся.

### 👥 Диллеры

`👥 Диллеры` → `➕ Добавить диллера` → имя. Бот даст ссылку: перешлите её диллеру, он нажмёт «Запустить».

| | Главный админ | Диллер |
|---|---|---|
| Серверы, скрипты, рассылка, диллеры | ✅ | ❌ |
| Создать ключ | ✅ | ✅ |
| Ключи | все (видно, чей ключ) | **только свои** |
| Файл, новая ссылка, продлить, отключить | любой ключ | только свой |

Диллер автоматически получает:
- 🌐 **при смене IP сервера** — сообщение и обновлённые файлы своих ключей (клиенты тоже получают новые ключи сами);
- 🔁 при переносе клиентов на другой сервер — новые файлы;
- 👤 уведомление, когда клиент открыл ссылку;
- ⏳ предупреждение, что у ключа заканчивается срок, и сообщение, когда ключ отключён.

**Лимит ключей:** карточка диллера → «🎚 Лимит ключей» → 5 / 10 / 20 / 50 / без лимита или своё число.
Считаются активные ключи: отключённые и истёкшие место не занимают, продление лимит не тратит.
Когда лимит исчерпан, диллер не может создать новый ключ и видит «Лимит исчерпан: 10 из 10».

### 🆘 Поддержка

У клиента в «🆘 Поддержка» есть кнопка **«✍️ Написать в поддержку»**. Вопрос (текст, фото или скрин) бот пересылает
**диллеру этого клиента**, а если ключ ваш, то вам. Под вопросом есть кнопка **«↩️ Ответить»**: ответ бот сам доставит клиенту.
Если у диллера есть @username, у клиента появится ещё кнопка «💬 Открыть чат».
Диллера можно заблокировать (⏸) или удалить: его ключи продолжат работать и перейдут вам.

### Что ещё бот делает сам

- ⏳ За 3 дня до конца срока предупреждает клиента, в срок отключает ключ (шаги «Удаление ключа»).
- ⚠️ Если сервер не отвечает, пишет вам и подсказывает, что делать.

## ⚡ Готовый OpenVPN: какие шаги заполнены

Для `scripts/openvpn-install.sh` (файл на сервере называется `vpn`):

| Поле | Значение |
|---|---|
| Установка | `chmod +x vpn` · `./vpn` · `? Public IPv4 address => {server_ip}` · `enter` · `n` · `2` · `443` · `1` · `9` · `n` · `y` · `3` · `2` ×7 · `v` · `admin` · `enter` |
| Проверка | `test -f /etc/openvpn/server.conf` |
| Создание ключа | `./vpn` · `1` · `{name}` · `enter` |
| Результат | файл `/root/{name}.ovpn` |
| Удаление ключа | `easyrsa revoke {name}` + обновление CRL + удаление `/root/{name}.ovpn` |
| Смена IP | `sed -i 's/{old_ip_re}/{new_ip}/g' /etc/openvpn/client-template.txt` (и `/root/*.ovpn`) |

Итог установки: порт **443/UDP**, DNS **Google (9)**, AES-256-GCM, RSA 3072, SHA-384, tls-auth.
Любой шаг можно поменять в карточке скрипта (`📜 Скрипты` → OpenVPN).
