# OpenVPN Seller Bot

Telegram-бот, через который клиенты получают ключи OpenVPN.
**Если IP сервера поменяется, бот сам пришлёт всем клиентам новые ключи.**

---

## 🚀 Установка: одна команда

Зайдите на сервер (Ubuntu / Debian / CentOS) под root и выполните:

```bash
bash <(curl -sL https://raw.githubusercontent.com/k9032431-cmd/OpenVPN-Seller-Bot/HEAD/install.sh)
```

Скрипт сам всё сделает и задаст только 2 вопроса:

1. **Токен бота.** Откройте [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя → скопируйте токен.
2. **Напишите своему боту «Start».** Так скрипт узнает ваш Telegram ID и сделает вас админом.

Если OpenVPN ещё не установлен, скрипт поставит и его.
Когда установка закончится, бот пришлёт вам сообщение «✅ Бот запущен».

## 🤖 Как пользоваться ботом

### Продать ключ (3 шага)

```
➕ Новый ключ  →  напишите имя (ahmet)  →  выберите срок (30 дней)
```

Бот даст **ссылку**. Перешлите её клиенту куда угодно (WhatsApp, Telegram…).

### Что видит клиент

1. Клиент открывает ссылку и нажимает **«Запустить»**.
2. Бот присылает ему файл `ahmet.ovpn`.
3. Клиент открывает файл в приложении **OpenVPN Connect** и подключается.

Ссылка срабатывает **один раз**: ключ привязывается к первому, кто её открыл.
Если переслать ссылку кому-то ещё, у него ключ не заработает.

У клиента в боте 4 кнопки: **🔑 Мой ключ**, **📅 Подписка**, **📲 Как подключиться**, **🆘 Поддержка**.

### Кнопки админа

| Кнопка | Что делает |
|---|---|
| ➕ **Новый ключ** | создать ключ и получить ссылку для клиента |
| 📋 **Ключи** | список ключей. Нажмите на ключ: файл, новая ссылка, +30 дней, отключить |
| 🌐 **IP сервера** | текущий IP; разослать ключи всем; сменить адрес вручную |
| 📢 **Рассылка** | написать сообщение всем клиентам |
| ❓ **Как это работает** | короткая инструкция прямо в боте |

### Что бот делает сам

- 🌐 **Каждую минуту проверяет IP сервера.** Если IP поменялся, бот обновляет ключи,
  рассылает новый файл всем клиентам и присылает вам отчёт.
- ⏳ **Следит за сроками.** За 3 дня бот предупреждает клиента, а когда срок закончился, отключает ключ.
- 🔄 **Подхватывает ключи, созданные вручную старым скриптом.** Они появятся в «📋 Ключи» с пометкой «создан скриптом».

## 🛠 Управление на сервере: команда `vpnbot`

```bash
vpnbot
```

Откроется меню: статус, логи, перезапуск, **обновление**, изменение настроек, меню OpenVPN, удаление.

---

## Как это устроено (для любопытных)

```
Клиент ──ссылка──▶ Telegram-бот ──▶ easy-rsa (/etc/openvpn) ──▶ файл .ovpn ──▶ клиенту
                        │
                        └─ раз в минуту: «какой у сервера IP?»
                           изменился → правит client-template.txt → рассылает всем новый .ovpn
```

| Файл | Что внутри |
|---|---|
| `install.sh` | установка одной командой |
| `vpnbot.sh` | меню управления (команда `vpnbot`) |
| `scripts/openvpn-install.sh` | ваш скрипт установки OpenVPN |
| `bot/handlers.py` | кнопки и команды бота |
| `bot/texts.py` | **все тексты бота**: можно поменять или перевести на туркменский |
| `bot/openvpn.py` | создание и отключение ключей (как в скрипте, но без вопросов) |
| `bot/services.py` | слежение за IP, сроками, рассылка |
| `.env` | настройки: токен, админы, интервал проверки IP |
| `bot.db` | база клиентов. **Делайте резервную копию вместе с `/etc/openvpn`** |

Бот установлен в `/opt/openvpn-seller-bot`.
Если в `.env` добавить несколько админов через запятую (`ADMIN_IDS=111,222`), управлять ботом смогут все они.
