# OpenVPN Seller Bot

Telegram-бот для продажи VPN. **Всё делается прямо в боте:**
вы добавляете серверы, бот сам ставит на них OpenVPN, создаёт ключи, раздаёт их клиентам
и, если сменился IP, рассылает всем новые ключи.

---

## 🚀 Установка: одна команда

Возьмите любой VPS (Ubuntu / Debian / CentOS): это может быть один из ваших VPN-серверов или отдельный.
Зайдите под root и выполните:

```bash
bash <(curl -sL https://raw.githubusercontent.com/k9032431-cmd/OpenVPN-Seller-Bot/HEAD/install.sh)
```

Скрипт задаст только 2 вопроса:
1. **Токен бота.** Откройте [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.
2. **Напишите своему боту «Start».** Так скрипт узнает ваш Telegram ID и сделает вас админом.

Всё остальное делается в боте.

---

## 🤖 Работа в боте

### 1. Добавьте сервер (один раз на каждый сервер)

```
🖥 Серверы → ➕ Добавить сервер → название → IP → пароль root
```

Бот подключится к серверу, удалит из чата сообщение с паролем и покажет кнопку
**⚙️ Установить OpenVPN**. Нажмите её и выберите **UDP 1194**: через 2–5 минут бот напишет «🎉 OpenVPN установлен».

> Пароль бот не хранит. Он заходит один раз, добавляет на сервер свой SSH-ключ
> и дальше работает по ключу.

### 2. Продайте ключ

```
➕ Новый ключ → (выбрать сервер) → имя: ahmet → срок: 30 дней
```

Бот даст **ссылку**. Перешлите её клиенту. Клиент нажмёт «Запустить», получит файл `.ovpn`
и откроет его в приложении OpenVPN Connect.
Ссылка срабатывает **один раз**: ключ привязывается к первому, кто её открыл.

### 3. Сменился IP сервера

```
🖥 Серверы → сервер → ✏️ Изменить IP → новый IP
```

Бот подключится по новому адресу, обновит ключи и **сам разошлёт их всем клиентам** этого сервера.

### 4. Сервер заблокировали или купили новый

```
➕ Добавить сервер (новый)  →  открыть старый сервер  →  🔁 Перенести клиентов
```

Каждый клиент получит новый ключ от нового сервера, сроки сохранятся.

### Что бот делает сам

- ⏳ **Сроки.** За 3 дня бот предупреждает клиента, а в срок отключает ключ.
- ⚠️ **Сервер не отвечает.** Бот пишет вам и подсказывает, что делать.
- 🌐 **Сервер, на котором стоит сам бот.** Если у него сменился IP, бот замечает это и рассылает ключи сам.
- 🔄 **Ключи, созданные вручную скриптом**, бот подхватывает автоматически.

### Все кнопки

| Кнопка | Что делает |
|---|---|
| ➕ **Новый ключ** | создать ключ и ссылку для клиента |
| 📋 **Ключи** | все ключи. Нажмите на ключ: файл, новая ссылка, +30 дней, отключить |
| 🖥 **Серверы** | добавить, установить OpenVPN, сменить IP, разослать ключи, перенести клиентов, удалить |
| 📢 **Рассылка** | сообщение всем клиентам |
| ❓ **Как это работает** | инструкция прямо в боте |

У клиента 4 кнопки: 🔑 Мой ключ · 📅 Подписка · 📲 Как подключиться · 🆘 Поддержка.

## 🛠 На сервере с ботом: команда `vpnbot`

```bash
vpnbot
```

Меню: статус, логи, перезапуск, обновление, изменение настроек, удаление.

## Как это устроено

```
          Telegram
             │
        ┌────┴─────┐   SSH (по ключу)   ┌──────────────┐
        │   Бот    │ ─────────────────▶ │ VPN-сервер 1 │  OpenVPN + easy-rsa
        │ (любой   │ ─────────────────▶ │ VPN-сервер 2 │
        │  VPS)    │ ─────────────────▶ │ ...          │
        └──────────┘                    └──────────────┘
```

Бот заходит на серверы по SSH и делает то же, что и ваш скрипт `scripts/openvpn-install.sh`,
только без вопросов: устанавливает OpenVPN, создаёт и отзывает ключи через easy-rsa, меняет адрес в
`/etc/openvpn/client-template.txt`.

| Файл | Что внутри |
|---|---|
| `install.sh` | установка одной командой |
| `vpnbot.sh` | меню управления (команда `vpnbot`) |
| `scripts/openvpn-install.sh` | ваш скрипт установки OpenVPN (бот запускает его на серверах) |
| `bot/handlers.py` | кнопки бота |
| `bot/texts.py` | **все тексты бота**: можно поменять или перевести на туркменский |
| `bot/openvpn.py` | ключи: создать, отозвать, собрать `.ovpn`, сменить адрес |
| `bot/remote.py` | подключение к серверам по SSH |
| `bot/services.py` | смена IP, перенос клиентов, проверки серверов и сроков |
| `.env` | настройки: токен, админы |
| `bot.db`, `data/ssh_key` | база клиентов и SSH-ключ бота. **Делайте их резервную копию!** |

Чтобы ботом управляли несколько админов, перечислите их ID в `.env` через запятую: `ADMIN_IDS=111,222`.
