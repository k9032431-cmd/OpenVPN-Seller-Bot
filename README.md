# OpenVPN Seller Bot

Telegram-бот для продажи и раздачи ключей OpenVPN.

- Вы создаёте ключ командой в боте и получаете **ссылку** для клиента.
- Клиент открывает ссылку и жмёт «Start», бот присылает ему `.ovpn` файл.
- **Если IP сервера изменился**, бот сам замечает это, обновляет адрес и **рассылает новые ключи всем клиентам**.
- Ключи со сроком действия (например, 30 дней): бот заранее предупреждает клиента и сам отключает ключ, когда срок закончится.
- У клиента есть меню: «Мой ключ», «Подписка», «Как подключиться», «Поддержка».

Бот работает с OpenVPN, установленным скриптом [`scripts/openvpn-install.sh`](scripts/openvpn-install.sh)
(пути `/etc/openvpn`, `/etc/openvpn/easy-rsa`, `client-template.txt`).

## Установка

1. Установите OpenVPN (если ещё не установлен):
   ```bash
   sudo bash scripts/openvpn-install.sh
   ```
2. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
   Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. Установите бота (спросит токен, ваш ID и контакт поддержки):
   ```bash
   git clone https://github.com/k9032431-cmd/OpenVPN-Seller-Bot.git
   cd OpenVPN-Seller-Bot
   sudo bash install.sh
   ```
4. Напишите боту `/start`, и он покажет команды администратора.

Бот работает как сервис и сам запускается после перезагрузки сервера.

```bash
journalctl -u openvpn-seller-bot -f     # логи
systemctl restart openvpn-seller-bot    # перезапуск (например, после правки .env)
```

## Как продавать ключ

```
/new ahmet 30 Ахмет +99361234567
```
Бот создаст сертификат на 30 дней и пришлёт ссылку вида `https://t.me/ваш_бот?start=...`.
Отправьте её клиенту. Ссылка привязывает ключ к **первому** аккаунту, который её открыл,
поэтому переслать её другому человеку не получится. Если клиент сменил аккаунт, выполните `/link ahmet`.

## Команды администратора

| Команда | Что делает |
|---|---|
| `/new имя [дней] [заметка]` | создать ключ (0 или пусто — бессрочно) |
| `/list` | все ключи |
| `/info имя` | подробности и ссылка |
| `/get имя` | получить `.ovpn` себе |
| `/link имя` | новая ссылка, старая привязка снимается |
| `/extend имя дней` | продлить (0 — сделать бессрочным) |
| `/revoke имя` | отключить ключ |
| `/sync` | добавить в бота ключи, созданные скриптом вручную |
| `/ip` | IP в ключах и реальный IP сервера |
| `/setip ip_или_домен` | сменить адрес вручную и разослать ключи всем |
| `/push` | разослать актуальные ключи всем клиентам |
| `/broadcast текст` | сообщение всем клиентам |

## Как работает смена IP

Каждые `IP_CHECK_INTERVAL` секунд (по умолчанию 60) бот узнаёт внешний IP сервера
(через ipify, icanhazip и другие сервисы) и сравнивает его с адресом в `client-template.txt`.
Если новый IP подтвердился `IP_CONFIRM_CHECKS` раз подряд, бот:

1. меняет строку `remote` в `/etc/openvpn/client-template.txt` (копия старой версии сохраняется в `.bak`);
2. собирает новый `.ovpn` для каждого активного клиента и присылает ему с пояснением;
3. сообщает администратору, скольким клиентам ключ дошёл.

Сертификаты при этом не меняются, клиенту нужно только импортировать новый файл.

> Если в ключах указан **домен** вместо IP (`/setip vpn.example.com`), бот не следит за IP:
> достаточно обновить DNS-запись, и старые ключи продолжат работать.

## Настройки (`.env`)

См. [`.env.example`](.env.example): токен, админы (можно несколько через запятую), контакт
поддержки, интервал проверки IP, за сколько дней предупреждать об окончании ключа.

Все тексты для клиентов находятся в [`bot/texts.py`](bot/texts.py). Их можно перевести, например, на туркменский.

## Важно

- Бот запускается от root, потому что ему нужен доступ к `/etc/openvpn/easy-rsa`.
- Отключённый (`/revoke`) клиент, который подключён прямо сейчас, отключится при следующем переподключении.
- Резервная копия: файл `bot.db` (клиенты и привязки) плюс папка `/etc/openvpn`.
